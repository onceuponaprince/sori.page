# Changelog

All notable changes to sori.page are documented here.

## [0.2.0] - 2026-05-25

### Auth & admin
- Centralized admin gates, super-admin bootstrap, dev session helpers, and clearer login errors.

### Stories
- Story library, create flow, and TipTap document persistence API.

### Simulation playground
- Django agent backend for character draft/publish, component submit, and threaded chat.
- Next.js agent proxies and tabbed playground UI (Talk, Scene, Characters) with novel/script format presets.

### Characters
- Search, sort, and delete in the playground character folder.

### Editor
- Scene goals and beat insertion from simulation into the manuscript editor.

### Billing
- Account billing section and credit-aware Stripe checkout/portal routes.

### Multiverse / timeline
- Twine import button, canon-leaf helpers, and timeline QA polish.

### Infrastructure
- Redis in Docker Compose, `start-stack.sh`, env example updates, and frontend dependency trim.
